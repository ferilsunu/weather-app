# Weather Platform (2020 Classic & 2026 NextGen)

A dual-mode atmospheric intelligence platform with real-time meteorological diagnostics, interactive radar, dynamic particle atmosphere, and legacy vintage interface compatibility.

## Features

- **Dual Experience Mode**: Seamless toggle between the nostalgic 2020 Minimalist UI and the 2026 Cyber-Luminous Glassmorphism Dashboard.
- **Atmospheric Particle Engine**: Live dynamic canvas background simulating rain, snow, fog, and celestial starlight in real time.
- **Full Meteorological Telemetry Matrix**:
  - Air Quality Index (US AQI, PM2.5, PM10, O3, NO2)
  - UV Radiation Gauge & Sunscreen Recommendations
  - 360° Compass Telemetry with Wind Speed & Gusts
  - Humidity, Dew Point & Comfort Index
  - Barometric Pressure & 24h Trend Tracker
  - Solar Arc (Live Sun Path, Sunrise & Sunset countdown)
  - Lunar Cycle & Illumination Percentage
  - 24-Hour Hourly Trajectory & 7-Day Extended Forecast
- **AI & Lifestyle Intelligence**: Running/workout score, commute safety, clothing and umbrella advice.
- **Interactive OpenStreetMap Radar**: Live geospatial precipitation and weather radar.
- **Security Hardened**:
  - Express + Helmet with strict Content Security Policy
  - Rate limiting against DDoS and API abuse
  - Input validation, sanitization, and SSRF prevention
  - Modern native async architecture with zero vulnerable dependencies
- **Ambient Web Audio Synthesizer**: Procedural acoustic atmosphere for rain, wind, and sunshine.

## Getting Started

### Prerequisites
- Node.js >= 18.0.0
- npm >= 9.0.0

### Installation

```bash
# Clone the repository
git clone https://github.com/ferilsunu/weather-app.git
cd weather-app

# Install dependencies
npm install

# Start the application
npm start
```

Default port is `3003` (or configured via `PORT` environment variable).
